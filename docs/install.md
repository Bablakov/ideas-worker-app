# Установка Ideas Worker

## 1. Установщик

1. Откройте страницу [Releases](https://github.com/Bablakov/ideas-worker-app/releases/latest) и скачайте
   `ideas-worker-x.y.z-setup.exe` из раздела **Assets**.
2. Запустите файл. Если Windows показывает «Windows защитила ваш компьютер» — нажмите **Подробнее** →
   **Выполнить в любом случае**. Установщик не подписан сертификатом: подпись платная и для домашнего
   приложения не нужна.
3. Выберите папку установки (по умолчанию — `%LOCALAPPDATA%\Programs\Ideas Worker`). Права администратора не нужны.
4. На рабочем столе и в меню «Пуск» появится ярлык **Ideas Worker**.

Приложение **не добавляет себя в автозапуск** и не работает в фоне после закрытия окна. Запускайте его,
когда хотите разобрать накопившиеся идеи.

Удаление: «Параметры → Приложения → Ideas Worker → Удалить». Настройки и скачанные карточки при этом
остаются в папке пользователя (`%APPDATA%\ideas-worker`); удалите её, если нужно убрать всё.

## 2. git и вход в GitHub

Ideas Worker забирает карточки через обычный `git`, поэтому ему не нужны токены, но нужен **git с сохранённым
входом** в ваш аккаунт GitHub.

1. Установите [Git for Windows](https://git-scm.com/download/win) (параметры по умолчанию подходят).
   В комплекте идёт Git Credential Manager — он сам запоминает вход.
2. Один раз выполните вход. Самый простой способ — в терминале:

   ```powershell
   git ls-remote https://github.com/ВАШ_ЛОГИН/ВАШ_РЕПОЗИТОРИЙ.git
   ```

   Откроется окно входа GitHub — войдите. После этого команда должна проходить **без вопросов**.
   Если вы пользуетесь GitHub CLI, подойдёт `gh auth login` и затем `gh auth setup-git`.
3. Перезапустите Ideas Worker, если он был открыт.

## 3. Первый запуск

1. Откройте **Настройки** → блок **«Репозиторий с карточками»**.
2. В поле **«Адрес репозитория»** укажите адрес вашего приватного репозитория данных, например
   `https://github.com/ВАШ_ЛОГИН/ideas-data.git`. Это тот же репозиторий, который вы указали в приложении «Идеи»
   на телефоне.
3. Нажмите **«Синхронизировать»** в верхнем правом углу. Первый раз приложение скачает копию репозитория.
4. Карточки появятся на вкладке **«Карточки»**.

В блоке **«Инструменты на этом компьютере»** зелёная точка означает, что инструмент найден. Красная — не найден;
рядом можно указать путь к нужному файлу.

## 4. Расшифровка и конспекты

**Расшифровка** нужна `ffmpeg` и один из движков — `parakeet` (быстрый) или `whisper` (точнее с пунктуацией).
Приложение их **не скачивает**, а ищет в привычных местах (`C:\Tools\ffmpeg`, `PATH` и т. п.). Если не нашло —
укажите пути в «Настройках»:

| Поле | Файл |
|---|---|
| ffmpeg | `ffmpeg.exe` |
| parakeet | `parakeet-cli.exe` и модель `.bin` |
| whisper | `whisper-cli.exe` и модель `.bin` |

Расшифровка начинается сама для каждой новой карточки с голосом или видео. Отключить: «Настройки» → «Расшифровка»
→ снять галочку «Расшифровывать новые карточки сами». Расшифровать вручную или заново можно кнопкой в карточке.

**Конспекты** делает локальная модель через `llama-server`. В блоке «Локальная модель для конспектов» нажмите
**«Запустить»**; модель грузится от нескольких секунд до нескольких минут (в первый раз, пока файл читается
с диска). Она считает на процессоре, видеокарта остаётся свободной. Закрывается вместе с приложением.

## Если что-то пошло не так

**«git не установлен».** Установите [git](https://git-scm.com/download/win) и перезапустите приложение.

**Ошибка доступа или пароля при синхронизации.** Проверьте вход командой из шага 2: она должна проходить без
вопросов. Если открывается окно входа — войдите, после этого повторите синхронизацию.

**«Репозиторий не найден».** Проверьте адрес в настройках и то, что вы вошли в тот аккаунт, у которого есть доступ
к репозиторию.

**Карточки не появляются.** Убедитесь, что на телефоне в «Настройках» заполнен токен и после записи нажата
кнопка «Синхрон.». Сам репозиторий можно открыть на сайте GitHub: в папке `inbox/` должны лежать папки карточек.

**«Не найден движок расшифровки».** Укажите пути к parakeet или whisper и модели в «Настройках».

**«Телефон ещё не догрузил карточку целиком».** Часть файла ещё не дошла из телефона. Дождитесь окончания
синхронизации на телефоне и нажмите «Синхронизировать» ещё раз.

**«Файл повреждён: контрольная сумма не совпала».** Часть файла пришла испорченной. На телефоне в «Настройках»
нажмите «Отправить мою версию на GitHub» — карточка загрузится заново.

**«Ветка на GitHub постоянно меняется».** Телефон и компьютер одновременно писали в репозиторий. Подождите
несколько секунд и повторите.

**Конспект не запускается.** Проверьте, что в блоке про локальную модель есть пути к `llama-server` и модели
(`.gguf`), и нажмите «Запустить». Подождите — в первый раз загрузка может быть долгой.

Если ничего не помогло — откройте [Issues](https://github.com/Bablakov/ideas-worker-app/issues) и приложите
текст ошибки из красной плашки (без паролей и токенов).
