# Связка телефона и компьютера

Приложение «Идеи» на телефоне и Ideas Worker на компьютере общаются только через **один приватный репозиторий
GitHub** (в примерах — `ideas-data`). Телефон кладёт туда карточки, компьютер их забирает и возвращает расшифровки.

```
телефон                            GitHub                              компьютер
«Идеи» ── токен ──►  приватный репозиторий ◄── git и ваш вход ──  Ideas Worker
```

## 1. Приватный репозиторий

Создайте на GitHub **приватный** репозиторий, например `ideas-data` (файлы в нём создавать не нужно: приложение
само заведёт папку `inbox/`). Если репозиторий публичный, ваши записи увидит кто угодно, поэтому приложение
на телефоне при проверке доступа предупредит, если он не приватный.

## 2. Телефон

1. Откройте [«Идеи»](https://bablakov.github.io/ideas-iphone/) в Safari (iPhone) или Chrome (Android) и добавьте
   на домашний экран («Поделиться» → «На экран „Домой“»).
2. Создайте токен на GitHub (с телефона это проще всего):
   - Settings → Developer settings → Personal access tokens → **Fine-grained tokens** → Generate new token;
   - **Repository access**: Only select repositories → ваш репозиторий с данными, и больше ничего;
   - **Permissions** → Repository permissions → **Contents: Read and write**;
   - скопируйте токен (он показывается один раз).
3. В приложении «Идеи»: **Настройки** → укажите репозиторий (`ваш_логин/ideas-data`), вставьте токен →
   **Проверить доступ**. Должно появиться «доступ на запись есть, репозиторий приватный».
4. Запишите тестовую карточку и нажмите **«Синхрон.»** в нижней панели.

Токен храните только на телефоне. Не присылайте его никому и не вставляйте в чаты и заметки.

## 3. Компьютер

1. Установите Ideas Worker: [инструкция](install.md).
2. Убедитесь, что `git` входит в ваш аккаунт без вопросов (шаг 2 в инструкции по установке).
3. В Ideas Worker: **Настройки** → адрес репозитория `https://github.com/ваш_логин/ideas-data.git` →
   **«Синхронизировать»**.

## 4. Проверка связки

1. Запишите на телефоне карточку с голосом и нажмите «Синхрон.».
2. В Ideas Worker нажмите «Синхронизировать» — карточка появится слева.
3. Расшифровка начнётся сама. Когда закончится — текст появится в карточке.
4. Нажмите «Обработана».
5. На телефоне нажмите «Синхрон.» — статус карточки обновится.

## Как приложения не мешают друг другу

- Телефон пишет в репозиторий через API GitHub, компьютер — через git. Если оба пишут одновременно, GitHub
  отвергает вторую запись, и приложение повторяет её на свежем состоянии (до нескольких раз подряд).
- Общий у них один файл — `item.json` карточки. Побеждает та версия, у которой позже время правки.
- Всё остальное разведено по разным файлам: телефон пишет файлы записи, компьютер — `transcript.txt`
  и `summary.md`.

## Что лежит в репозитории

```
inbox/
  <id карточки>/
    item.json        текст, ссылка, статус, даты, описание файлов (контрольные суммы)
    audio.000, …     аудио кусками по 10 МБ
    video.000, …     видео кусками по 10 МБ
    transcript.txt   расшифровка (пишет Ideas Worker)
    summary.md       конспект (пишет Ideas Worker)
```

Если карточку удалить на телефоне, файлы записи стираются, а `item.json` остаётся с пометкой `deleted: true` —
по ней другие устройства узнают об удалении.
