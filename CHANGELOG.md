# История версий

## 0.1.0 — 27 октября 2026

Первый выпуск.

**Основное**

- Забирает карточки из приватного репозитория `ideas-data` (голос, видео, текст, ссылки из приложения «Идеи»).
  Большие записи, отправленные кусками, склеиваются; размер и контрольная сумма каждого куска проверяются.
- Локальная расшифровка голоса и видео: parakeet (быстро) или whisper (точнее), для длинных записей можно
  выбрать другой движок. Новые карточки расшифровываются сами по очереди, можно выключить.
- Конспект по кнопке локальной моделью (llama-server): заголовок и список основных мыслей, без выдумок.
- Статусы «Обработана», «В архив», «Вернуть» меняются в приложении и видны на телефоне.
- Список карточек по дням с фильтрами «Необработанные / Обработанные / Архив / Все» и диапазоном дат,
  плеер с перемоткой, кнопки «Копировать», «Открыть папку карточки».

**Надёжность**

- Если телефон сдвинул ветку репозитория во время записи, отправка повторяется на свежем состоянии.
- Исходный текст карточки и расшифровка не перезаписываются конспектом.
- Повреждённая карточка не мешает остальным: ошибка показывается в настройках.

**Установка**

- Установщик для Windows с выбором папки, без прав администратора, без автозапуска.
- Установщик не подписан сертификатом: Windows SmartScreen предупредит о неизвестном издателе.
